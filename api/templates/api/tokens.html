Connect an AI assistant

SN EOS is an MCP server (streamable HTTP). Point your client at:

{{ base_url }}/mcp 
{
  "mcpServers": {
    "sn-eos": {
      "url": "{{ base_url }}/mcp",
      "headers": { "Authorization": "Bearer sneos_…" }
    }
  }
}
curl -H "Authorization: Bearer sneos_…" \
  {{ base_url }}/api/v1/rocks?mine=true

curl -X POST -H "Authorization: Bearer sneos_…" \
  -H "Content-Type: application/json" \
  -d '{"week":"2026-11-16","value":42}' \
  {{ base_url }}/api/v1/measurables/7/values

Tokens act as you: they can only change what you can change in the app. Read-only tokens hide the write tools.
